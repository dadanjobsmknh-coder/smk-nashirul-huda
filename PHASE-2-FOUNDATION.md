# Phase 2 Foundation Deliverables

- Struktur proyek multi-page.
- Design tokens dan CSS modular.
- Header/footer partial.
- Navbar desktop dan mobile accordion.
- Search overlay.
- Modal aksesibel dengan focus management.
- JSON loader, validator, dan error state.
- Placeholder routes untuk modul berikutnya.
- README, panduan verifikasi data, manifest, robots, dan sitemap placeholder.
