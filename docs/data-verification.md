# Log Verifikasi Data

## Perlu dikonfirmasi sebelum produksi

- Ejaan dan gelar kepala sekolah.
- RT/RW alamat sekolah.
- Email resmi publik.
- Kepanjangan resmi CAKEP.
- Data SPMB aktif setelah 2026.
- Daftar fasilitas dan foto resmi.
- Data personal yang diizinkan untuk dipublikasikan.

Data berstatus `needs-review` tidak boleh dirender ke website produksi.
