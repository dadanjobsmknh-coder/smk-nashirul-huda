# Mobile Navbar Collapse

- Navigasi desktop disembunyikan pada lebar maksimal 64rem.
- Logo, tombol pencarian, dan tombol hamburger tetap terlihat.
- Tombol SPMB desktop disembunyikan dan tetap tersedia di menu seluler.
- Panel menu seluler muncul dari sisi kanan dan dapat digulir.
- Tinggi panel menyesuaikan layar menggunakan `100dvh`.
- Cache diperbarui ke `v20-mobile-navbar-collapse`.
