# Phase 3 Homepage

## Implemented

- Hero slideshow tiga slide dengan autoplay, kontrol, dot navigation, dan reduced-motion support.
- Quick actions.
- Intro dan statistik sekolah.
- Keunggulan sekolah.
- Sambutan kepala sekolah sementara.
- Panel PPLG dan MPLB.
- CTA SPMB dengan informasi kedaluwarsa ditandai sebagai arsip.
- Berita, agenda, pengumuman, guru, ekstrakurikuler, prestasi, fasilitas, dan mitra berbasis JSON.
- Kontak dan placeholder peta.
- Local SVG visual placeholders.
- Responsive layouts dan professional empty states.

## Important

Berita, prestasi, dan mitra tetap kosong karena belum ada data terverifikasi. Homepage tidak membuat fakta fiktif untuk mengisi bagian tersebut.
